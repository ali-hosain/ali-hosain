## 🚀 Featured Project

### [Toroid Studio](https://github.com/ali-hosain/toroid-studio) — AI-Powered Android IDE
A production-grade mobile IDE for Android with native Claude AI integration.

**14 phases shipped — highlights:**
- 🤖 AI chat, inline completions & agentic code editing (approval-gated)
- 🐍 Python (Chaquopy) + Node.js runtimes on-device
- 🔍 LSP — real diagnostics, go-to-definition, autocomplete (Python & TypeScript)
- 🐛 Python debugger (debugpy / DAP protocol)
- 🌿 Full Git workflow + merge conflict UI
- ☁️ Google Drive cloud sync, one-tap Netlify deploy
- 🔒 All AI file mutations gated behind Approve/Reject diff preview

> **Play Store launch coming soon.**
